# HPLC Tool — Worked Session

This repository is the worked-session copy of the HPLC Tool.

When served through GitHub Pages, `index.html` automatically loads the real Group 09 chromatogram CSV files in `worked-session/` through the tool's normal CSV importer.

Pre-filled method specifications:
- Target peak count: 7
- Maximum last-peak retention time: 15 min
- Minimum worst adjacent resolution: 1.4
- Maximum back pressure: 4000 psi
- Starting solvent: ACN
- Peak-height threshold: 10,000 counts

Included experimental runs: 05, 06, 07, 08, 09, 10, 14, 15 and 16.

The GR11 MeOH/BiPH file is intentionally excluded because it belongs to another group.


Note: The worked session also includes `GR11-16-6-MeOH-3-ISO-50-1.5-20u-CP-0.1-BiPH-150x4.6x5-amb-254.csv` as supplied by the student.
